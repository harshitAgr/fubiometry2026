# FU_Biometry 2026 — Multi-Task Ultrasound Biometry Landmark Detection

Code release accompanying our method paper for the **FU_Biometry 2026** challenge
(Foundation Model for Ultrasound Biometry, MICCAI 2026 / MWM 2026).

This repository covers **only the methods used in the final hidden-test submission**:
a unified landmark-detection system spanning nine task IDs across prenatal,
intrapartum, and adult cardiac ultrasound, scored on landmark mean radial error and
derived clinical-parameter error.

> **Status: release in preparation.** The final-test phase closes 15 August 2026.
> The inference code, training recipes, and the offline container definition for the
> deployed system will be published here after the phase closes.
